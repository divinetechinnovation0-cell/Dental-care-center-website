# Dental Care Center Pvt. Ltd. — Website

A premium, modern website built for Dental Care Center Pvt. Ltd., New Baneshwor, Kathmandu.

## Quick Start (Local)

```bash
npm install
npm run dev
```

Then open http://localhost:5173 in your browser.

## Deploy to Vercel (Easiest)

### Option A: Via GitHub (Recommended)
1. Push this folder to a GitHub repo
2. Go to https://vercel.com and sign in with GitHub
3. Click "Add New Project" → Import the repo
4. Vercel auto-detects Vite — just click "Deploy"
5. Done! You get a live URL like `dental-care-center.vercel.app`

### Option B: Via Vercel CLI
```bash
npm install -g vercel
vercel
```
Follow the prompts. It deploys in ~30 seconds.

## Build for Production

```bash
npm run build
```

Output goes to the `dist/` folder — can be hosted anywhere (Netlify, shared hosting, etc.)

## Tech Stack
- React 18
- Vite 5
- Lucide React (icons)
- Pure CSS animations (no heavy libraries)

## Customization
- Colors: Edit the `colors` object at the top of `src/App.jsx`
- Content: Edit the data arrays (services, team, testimonials, faqs) in `src/App.jsx`
- Photos: Replace placeholder divs with actual `<img>` tags
